# 🤖 بوت مراقبة القنوات (Multi-Tenant Channel Watcher Bot)

بوت تليكرام احترافي متعدد المستخدمين (Multi-Tenant) مبني بلغة Python باستخدام **Aiogram 3** و **SQLAlchemy (Async)**، يتيح لأي مستخدم إضافة قناته الخاصة وتعيين البوت مشرفاً فيها، وعند مغادرة أي عضو من القناة، يرسل البوت إشعاراً فورياً وتفصيلياً إلى **مالك تلك القناة حصراً**.

## ✨ المزايا الرئيسية

| الميزة | الوصف |
|---|---|
| 🏢 **تعدد المستأجرين (Multi-Tenant)** | كل مستخدم يدير قنواته الخاصة بشكل مستقل تماماً عبر قاعدة بيانات مركزية |
| 🔄 **تسجيل تلقائي للقنوات** | عند رفع البوت مشرفاً في أي قناة، يتم تسجيلها فوراً وربطها بمالكها |
| 🚨 **رصد المغادرة الفوري** | إشعار خاص فوري لمالك القناة عند مغادرة/طرد أي عضو، مع كامل التفاصيل |
| 🔐 **اشتراك إجباري (Force Subscription)** | لا يمكن استخدام البوت إلا بعد الاشتراك بقناة المطور |
| 🎛️ **لوحة تحكم كاملة** | عرض القنوات، تفعيل/تعطيل الإشعارات، حذف قناة من المتابعة |
| 📊 **إحصائيات المطور** | أمر خاص بالمطور لعرض عدد المستخدمين والقنوات المراقَبة |
| 🗄️ **قاعدة بيانات Async** | SQLite + SQLAlchemy 2.0 (ORM) + aiosqlite لأداء غير متزامن بالكامل |
| ⚡ **Aiogram 3** | أحدث إصدار من أشهر مكتبات بوتات تليكرام في بايثون |

## ⚙️ متطلبات التشغيل

- Python **3.10** أو أحدث
- توكن بوت تليكرام (من [@BotFather](https://t.me/BotFather))
- قناة تليكرام تستخدم للاشتراك الإجباري، مع رفع البوت فيها كمشرف

## 🚀 التثبيت والتشغيل المحلي

### 1. استنساخ المشروع

```bash
git clone https://github.com/your-username/telegram-channel-watcher-bot.git
cd telegram-channel-watcher-bot
```

### 2. إنشاء بيئة افتراضية (اختياري لكن موصى به)

```bash
python -m venv venv

# تفعيل البيئة الافتراضية
source venv/bin/activate      # على Linux / macOS
venv\Scripts\activate         # على Windows
```

### 3. تثبيت المكتبات

```bash
pip install -r requirements.txt
```

### 4. إعداد ملف البيئة

```bash
cp .env.example .env
```

ثم افتح ملف `.env` وعبّئ القيم المطلوبة (راجع القسم التالي).

### 5. تشغيل البوت

```bash
python main.py
```

عند نجاح التشغيل ستظهر رسالة في الطرفية تفيد بأن البوت يعمل الآن وينتظر التحديثات، وسيتم إنشاء ملف قاعدة البيانات (`bot_database.db`) تلقائياً في المجلد الرئيسي.

## 🔑 شرح متغيرات البيئة

| المتغير | الوصف | مثال |
|---|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather | `123456789:AAExampleToken` |
| `DEV_ID` | آيدي المطور الرقمي (يُستثنى من الاشتراك الإجباري ويصل له أمر `/stats`) | `123456789` |
| `DEV_CHANNEL` | قناة الاشتراك الإجباري، يمكن كتابتها بصيغة `@username` أو آيدي رقمي `-100xxxxxxxxxx` | `@my_channel` |
| `DEV_USERNAME` | يوزر المطور بدون `@`، يُستخدم في زر "تواصل مع المطور" | `dev_username` |
| `DB_PATH` | مسار ملف قاعدة بيانات SQLite | `bot_database.db` |

> 💡 يمكنك معرفة آيدي حسابك (`DEV_ID`) عبر إرسال أي رسالة لبوت [@userinfobot](https://t.me/userinfobot).

> ⚠️ إذا تركت `DEV_CHANNEL` فارغة، سيتم تعطيل نظام الاشتراك الإجباري بالكامل تلقائياً.

## 🛡 إعداد صلاحيات البوت في القنوات

### أ) قناة الاشتراك الإجباري (`DEV_CHANNEL`)
يجب رفع البوت **كمشرف** في هذه القناة (ولو بصلاحيات محدودة) حتى يتمكن من التحقق من عضوية المستخدمين عبر `get_chat_member`.

### ب) قنوات المستخدمين (القنوات المراد مراقبتها)
عندما يقوم أي مستخدم برفع البوت **كمشرف** في قناته الخاصة، يقوم البوت تلقائياً بـ:
1. تسجيل القناة في قاعدة البيانات وربطها بآيدي المستخدم الذي رفعه.
2. إرسال رسالة تأكيد للمستخدم في الخاص.

**⚠️ مهم جداً:** لكي يتمكن البوت من رصد مغادرة الأعضاء، يجب منحه صلاحية **"إضافة/دعوة أعضاء"** أو أي صلاحية إدارية عند الترقية (يفضل تفعيل جميع الصلاحيات المتاحة عند إضافته لضمان استقبال جميع الأحداث بشكل صحيح من طرف تليكرام).

## 🎮 أوامر البوت

| الأمر | الوصف | المستخدم |
|---|---|---|
| `/start` | بدء استخدام البوت وعرض القائمة الرئيسية | الجميع |
| `/stats` | عرض إحصائيات البوت (عدد المستخدمين والقنوات) | المطور فقط |

### الأزرار التفاعلية
- **➕ إضافة البوت إلى قناتك** — رابط مباشر (`startchannel`) لإضافة البوت وترقيته في قناة جديدة.
- **📡 قنواتي** — عرض كل القنوات المسجلة باسم المستخدم، مع إمكانية الدخول لكل قناة لإدارتها.
- **🔔 / 🔕 تفعيل/تعطيل الإشعارات** — التحكم بتلقي إشعارات المغادرة لكل قناة على حدة.
- **🗑 حذف قناة** — إزالة قناة من قائمة المتابعة (مع رسالة تأكيد قبل الحذف النهائي).
- **👨‍💻 تواصل مع المطور** — رابط مباشر لحساب المطور.

## 🔍 آلية عمل رصد المغادرة

يعتمد البوت على حدث `ChatMemberUpdated` الذي يرسله تليكرام تلقائياً عند تغيّر حالة عضوية أي مستخدم داخل القناة، ويُفرّق بين حالتين:

1. **`my_chat_member`**: يتتبع تغيّر حالة **البوت نفسه** (تمت ترقيته/إزالته) → يُستخدم لتسجيل/حذف القناة تلقائياً.
2. **`chat_member`**: يتتبع تغيّر حالة **أي عضو آخر** في القناة (من `member`/`administrator` إلى `left`/`kicked`) → يُستخدم لإرسال إشعار المغادرة.

عند رصد مغادرة، تُرسل رسالة لمالك القناة تحتوي على:
- 📡 اسم القناة
- 👤 الاسم الكامل للعضو المغادر
- 🔗 المعرف (Username) كرابط قابل للنقر (أو إشعار بعدم وجود يوزر)
- 🆔 آيدي المستخدم (User ID)
- 📱 رقم الهاتف — **غير متوفر تقنياً** إلا إذا شارك العضو رقمه صراحة مع البوت مسبقاً (قيد سياسة خصوصية تليكرام؛ لا توجد واجهة برمجية تتيح للبوتات الوصول لأرقام هواتف أعضاء القنوات)
- 📌 نوع المغادرة (طوعية / طرد)
- 🕒 التاريخ والوقت بدقة

## ☁️ النشر على سيرفر

### الخيار الأول: VPS (Ubuntu مثلاً)

```bash
sudo apt update && sudo apt install python3-pip python3-venv -y
git clone https://github.com/your-username/telegram-channel-watcher-bot.git
cd telegram-channel-watcher-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env && nano .env   # عبّئ القيم ثم احفظ

# تشغيل دائم باستخدام systemd (مستحسن) أو screen/tmux
screen -S mybot
python main.py
# اضغط Ctrl+A ثم D للخروج دون إيقاف البوت
```

**تشغيل عبر systemd (موصى به للإنتاج):**

أنشئ ملف `/etc/systemd/system/channelbot.service`:

```ini
[Unit]
Description=Telegram Channel Watcher Bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/path/to/telegram-channel-watcher-bot
ExecStart=/path/to/telegram-channel-watcher-bot/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

ثم فعّله:

```bash
sudo systemctl daemon-reload
sudo systemctl enable channelbot
sudo systemctl start channelbot
sudo systemctl status channelbot
```

### الخيار الثاني: Railway / Render

1. ارفع المشروع إلى GitHub.
2. أنشئ مشروعاً جديداً على [Railway](https://railway.app) أو [Render](https://render.com) واربطه بالمستودع.
3. أضف متغيرات البيئة (`BOT_TOKEN`, `DEV_ID`, `DEV_CHANNEL`, `DEV_USERNAME`) من إعدادات المنصة.
4. اضبط أمر التشغيل (Start Command) على: `python main.py`.

> ⚠️ ملاحظة: في المنصات ذات نظام الملفات المؤقت (Ephemeral)، قد تُحذف قاعدة بيانات SQLite عند كل إعادة نشر. للاستخدام الإنتاجي طويل الأمد يُفضّل ربط تخزين دائم (Volume) أو الانتقال لاحقاً إلى PostgreSQL.

## ❓ الأسئلة الشائعة

**س: لماذا لا يظهر رقم هاتف العضو المغادر؟**
لا تسمح واجهة تليكرام البرمجية (Bot API) بتاتاً للبوتات بالوصول لأرقام هواتف أعضاء القنوات، إلا إذا شارك العضو رقمه صراحة مع البوت عبر زر "مشاركة جهة الاتصال" في محادثة خاصة سابقة. هذا قيد من تليكرام نفسه وليس من البوت.

**س: البوت لا يرسل لي إشعارات المغادرة؟**
تأكد من:
1. أن البوت لا يزال مشرفاً في القناة.
2. أنك بدأت محادثة خاصة مع البوت (اضغط /start في الخاص) حتى يستطيع مراسلتك.
3. أن الإشعارات مُفعّلة للقناة من قائمة «قنواتي».
4. أن `allowed_updates` عند التشغيل يتضمن `chat_member` (مُفعّل افتراضياً في هذا المشروع).

**س: هل يمكن استخدام قاعدة بيانات أخرى غير SQLite؟**
نعم، بفضل استخدام SQLAlchemy Async يمكنك استبدال رابط الاتصال في `bot/database/db.py` (مثلاً بـ PostgreSQL عبر `asyncpg`) مع تعديل بسيط في `requirements.txt`.
